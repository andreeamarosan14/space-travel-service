# Space travel service

A prototype built with the GOV.UK Prototype Kit for an interaction designer test.

## Pages

- Start page
- Where would you like to travel
- Moon trip or Mars trip, depending on the answer
- Full name
- Address
- Check your answers
- Confirmation

## Run locally

You need Node.js 18 or later.

    npm install
    npm run dev

Then go to http://localhost:3000

## Deploy to Render

- Create a new Web Service and connect this repo
- Build command: npm install
- Start command: npm start
- Add an environment variable called PASSWORD
